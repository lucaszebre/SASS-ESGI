Accordéon (.accordion)

BEM (Block Element Modifier) est une méthodologie de nommage CSS qui aide à créer des composants réutilisables et maintenables.

L'approche mobile-first consiste à écrire les styles pour mobile en premier, puis à ajouter des media queries pour les écrans plus larges.

Le dark mode s'active via la classe .dark sur l'élément <html> ou automatiquement via les préférences système.
